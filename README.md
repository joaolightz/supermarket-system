# 🛒 Sistema de Supermercado

Sistema de gerenciamento de supermercado desenvolvido em Java com o objetivo de praticar Programação Orientada a Objetos (POO), organização de código e controle de versão com Git.

## 📌 Sobre o projeto

O Sistema de Supermercado é um projeto pessoal que busca simular as principais operações de um supermercado por meio de uma aplicação Java.

O projeto está sendo desenvolvido gradualmente, com foco em código organizado, princípios da orientação a objetos e boas práticas de programação.

## ✨ Funcionalidades

- **Gerenciamento de produtos:** cadastro e gerenciamento de produtos e preços.
- **Gerenciamento de funcionários:** organização de informações, jornadas de trabalho e salários.
- **Autenticação:** controle de acesso para gerentes e funcionários autorizados.
- **Regras de negócio:** modelagem das operações de um supermercado utilizando orientação a objetos.

*As funcionalidades estão sendo implementadas gradualmente conforme a evolução do projeto.*

## 🛠️ Tecnologias utilizadas

- Java
- Git
- GitHub
- IntelliJ IDEA

## 📚 Conceitos praticados

- Programação Orientada a Objetos (POO)
- Classes, objetos e construtores
- Encapsulamento, herança e polimorfismo
- Interfaces e classes abstratas
- Tratamento de exceções
- Organização de código e baixo acoplamento
- Controle de versão com Git

## 🚀 Como executar o projeto

### Pré-requisitos

- JDK do Java instalado
- Uma IDE, como IntelliJ IDEA (opcional)

### Instalação

1. Clone o repositório:

   ```bash
   git clone https://github.com/joaolightz/supermarket-system.git
   ```

2. Abra o projeto na sua IDE de preferência.

3. Configure o JDK do Java.

4. Execute a classe principal do projeto.
